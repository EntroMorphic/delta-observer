# NODES: native fit bottleneck

1. Perfect primitive fit does not imply compound fit.
2. Task isolation did not repair compounds; other-task interference is not enough.
3. Epoch count and rank have never been controlled.
4. Training has 512 arithmetic rows, including 128 final-only compounds.
5. Exposed test accuracy cannot select checkpoints without becoming development.
6. Native model must stay intact; no hidden symbolic solver to manufacture 100/100.
7. Retention is a separate gate from local fit.

Tensions: training fit versus transfer; repetitions versus capacity; task-specific
gain versus general regression; finish-the-goal pressure versus honest measurement.
